## 项目是什么

EmbyBox：插件化的 Emby / Jellyfin 媒体服务运营系统。一个 Go 内核 + 四类插件，把"片源获取、用户与权益、用量统计、线路与运维、保号、自建门户"这六类工具收进一个部署单元。核心永久免费（AGPL-3.0），专业版提供多租户与企业能力。

当前状态：设计阶段。内核骨架（`pkg/kernel/` 的 contract / registry / event / plugin / httpapi / store / config / schedule / assemble）已实现且 `go build ./...`、`go vet ./...` 通过；**业务表 0 张、业务端点 0 个、`cmd/embybox/main.go` 未写**。这些是已知状态，不是缺陷。

## 硬性要求

1. 每条结论必须给 `文件:行号`。没有行号的建议直接不要写。
2. 每条结论必须归入三类之一，并显式标注：
